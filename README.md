# Mi mes

App para el iPhone que calcula cuánto dinero tengo libre hasta el próximo cobro y cuánto puedo gastar al día.

- Pendientes con casilla: fijos, deudas y otros gastos; al marcarlos pasan a "Cobrados".
- Fijos con frecuencia (cada mes, cada 2 meses…) e importe distinto algunos meses.
- Deudas con sus cuotas, caprichos, modo claro/oscuro y fondos de color.

Los datos se guardan solo en el propio iPhone (no en este repositorio). Desde Ajustes se puede hacer y cargar una copia de seguridad.

Uso: abrir la web de GitHub Pages en Safari → Compartir → Añadir a pantalla de inicio.
